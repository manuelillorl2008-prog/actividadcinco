# Actividad Cinco

## Descripción
Este proyecto consiste en el desarrollo de una landing page utilizando Reflex.  
La página fue inspirada en diseños modernos encontrados en plataformas de inspiración visual como Landingfolio.

La landing page incluye:
- Barra de navegación
- Sección principal (Hero)
- Botones interactivos
- Sección informativa
- Página de inicio de sesión
- Página de creación de cuenta
- Footer

## Tecnologías utilizadas
- Python
- Reflex
- HTML/CSS generado por Reflex

## Componentes utilizados
- Containers
- VStack
- HStack
- Grid
- Box
- Buttons
- Inputs
- Links

## Funcionalidades
- Navegación entre páginas
- Diseño moderno y responsivo
- Formularios de login y registro
- Botones interactivos
